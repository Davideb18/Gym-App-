# Gym App - Project Requirements Document (PRD) v2.0

## 1. Overview
A mobile application for gym-goers to track their workouts, analyze performance, and receive AI-driven advice. The project aims to be a **scalable startup-ready** application and a **tier-1 portfolio piece**.

## 2. Core Features (MVP)
- **User Profiles**: Personal information, fitness goals, and history.
- **Workout Tracker**: Real-time logging of exercises, sets, reps, and weight.
- **Training Cards (Schede)**: Pre-defined or custom-made exercise routines.
- **Progress Analytics**: Visualization of volume, strength gains, and consistency.
- **AI Coach**: LLM-powered suggestions for load adjustments and workout variety.

## 3. Scalability & Business Model
- **Subscription Model**: Premium features (AI Coach, Pose Estimation) for **€3/month**.
- **Scalable Infrastructure**: Designed to handle 100k+ concurrent users with a modular backend and optimized database queries.
- **Target Metrics**: 5% conversion rate from free to paid users.

## 4. Technical Excellence (CV Impact)
- **Clean Architecture**: Decoupled layers for maximum testability.
- **TypeScript First**: End-to-end type safety.
- **CI/CD & Monitoring**: Professional development lifecycle.

## 5. Collaboration Strategy
- **Backend (User)**: API development, database schema, AI integration, infrastructure.
- **Frontend (Partner)**: UI/UX design, mobile app screens, state management.
